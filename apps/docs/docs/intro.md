# 什么是智安哨

智安哨是一个面向 LLM Agent 的攻击面研究与行为监督平台。

它不是普通后台页面，而是把红队攻击复现、工具调用监督、审计告警、防御评测和比赛交付材料串起来的本地安全靶场。

## 项目定位

| 项目 | 内容 |
| --- | --- |
| 中文名 | 智安哨 |
| 英文名 | Agent Security Supervisor |
| 代码包名 | `agent_supervisor` |
| 核心对象 | 会调用文件、邮件、API、代码执行、记忆等工具的 LLM Agent |
| 安全边界 | 只攻击本地沙箱和模拟比赛数据，不攻击真实外部系统 |

## 核心能力

- 研究 7 类智能体攻击面。
- 维护 22 个可复现攻击剧本。
- 使用 13 条防御策略监督工具调用。
- 生成审计日志、告警、证据包和评测报告。
- 提供 OpenClaw 兼容事件入口和插件包。
