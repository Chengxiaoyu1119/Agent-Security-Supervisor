# 防御策略

智安哨当前内置 13 条防御策略，输出四类决策：允许、拒绝、询问、隔离。

| 策略 | 决策 | 作用 |
| --- | --- | --- |
| 文件沙箱边界 | 拒绝 | 禁止读取沙箱外路径和敏感目录 |
| 危险命令拦截 | 拒绝 | 拦截删除、格式化、联网下载、提权等命令 |
| 代码执行沙箱 | 隔离 | 代码执行默认进入沙箱和白名单 |
| 邮件外发询问 | 询问 | 外部收件人邮件需要人工确认 |
| 高敏 API 审计 | 拒绝 | 禁止无授权访问队伍、提交物、榜单和赛题种子 |
| 记忆写入隔离 | 隔离 | 高风险长期记忆写入进入隔离区 |
| 敏感记忆读取拦截 | 拒绝 | 拦截 secret、token、team、flag 等记忆检索词 |
| 越狱提示过滤 | 拒绝 | 识别忽略规则和无约束角色提示 |
| 模型输出过滤 | 拒绝 | 拦截训练样例复述和高风险绕过指导 |
| 批量动作复核 | 询问 | 批量导出、批量外发需要人工复核 |
| 工具返回低信任隔离 | 隔离 | 工具返回内容不能作为授权依据 |
| 环境信息低信任隔离 | 隔离 | 环境变量和配置不能覆盖安全策略 |
| 轻量异常检测 | 询问 | 固定规则未命中但组合异常时触发复核 |
