# 常见问题

## 没有真实模型密钥能不能运行

可以。项目默认会回退到本地模拟模型，仍然能演示攻击复现、行为监督、告警、审计和报告。

## 页面能打开是不是后端就正常了

不是。控制台在后端离线时会使用内置样本数据。要写入真实实验日志，需要启动 `npm run api`。

## 为什么后端叫 apps/api

因为它是对外提供 HTTP 接口的服务。`api` 比 `backend` 更清楚地表达职责。

## 为什么控制台叫 apps/console

因为当前 React 页面是项目主控制台，不是唯一前端。官网和文档站也是前端，所以不建议把控制台叫 `frontend`。

## 根目录 docs 是什么

根目录 `docs` 保留历史开发记录、方案和过程材料。正式文档站在 `apps/docs`。
